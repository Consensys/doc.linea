### Transaction validator

Config-file key: `transaction-validator-config`

| Option                                    | Description                                                | Default | Type    | Visibility |
| ----------------------------------------- | ---------------------------------------------------------- | ------- | ------- | ---------- |
| `--plugin-linea-blob-tx-enabled`          | Enable blob transactions? (default: false)                 | `false` | BOOLEAN | Advanced   |
| `--plugin-linea-delegate-code-tx-enabled` | Enable EIP7702 delegate code transactions? (default: true) | `true`  | BOOLEAN | Advanced   |
