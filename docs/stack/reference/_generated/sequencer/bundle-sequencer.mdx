### Bundle

Config-file key: `bundle-sequencer`

| Option                                       | Description                                                                                  | Default | Type           | Visibility |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- | ------- | -------------- | ---------- |
| `--plugin-linea-bundles-forward-urls`        | A comma separated list of endpoint to which incoming bundles will be forwarded (default: []) | `[]`    | SET&lt;URL&gt; | Standard   |
| `--plugin-linea-bundles-forward-retry-delay` | Number of milliseconds to wait before retrying a failed forward (default: 1000)              | `1000`  | INTEGER        | Standard   |
| `--plugin-linea-bundles-forward-timeout`     | Number of milliseconds to wait before a forward times out (default: 5000)                    | `5000`  | INTEGER        | Standard   |
