### Profitability

Config-file key: `profitability-config`

| Option                                                   | Description                                                                                                                                                                                                          | Default                                                         | Type    | Visibility |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------- | ---------- |
| `--plugin-linea-fixed-gas-cost-wei`                      | Fixed gas cost in Wei (default: 0)                                                                                                                                                                                   | `0`                                                             | INTEGER | Advanced   |
| `--plugin-linea-variable-gas-cost-wei`                   | Variable gas cost in Wei (default: 10000000000)                                                                                                                                                                      | `10000000000`                                                   | INTEGER | Advanced   |
| `--plugin-linea-min-margin`                              | Minimum margin of a transaction to be selected (default: 1)                                                                                                                                                          | `1`                                                             | FLOAT   | Advanced   |
| `--plugin-linea-estimate-gas-min-margin`                 | Recommend a specific gas price when using linea_estimateGas (default: 1)                                                                                                                                             | `1`                                                             | FLOAT   | Advanced   |
| `--plugin-linea-tx-pool-min-margin`                      | The min margin an incoming tx must have to be accepted in the txpool (default: 0.5)                                                                                                                                  | `0.5`                                                           | FLOAT   | Advanced   |
| `--plugin-linea-tx-pool-profitability-check-api-enabled` | Enable the profitability check for txs received via API? (default: true)                                                                                                                                             | `true`                                                          | BOOLEAN | Advanced   |
| `--plugin-linea-tx-pool-profitability-check-p2p-enabled` | Enable the profitability check for txs received via p2p? (default: false)                                                                                                                                            | `false`                                                         | BOOLEAN | Advanced   |
| `--plugin-linea-extra-data-pricing-enabled`              | Enable setting pricing parameters via extra data field (default: false)                                                                                                                                              | `false`                                                         | BOOLEAN | Advanced   |
| `--plugin-linea-extra-data-set-min-gas-price-enabled`    | Enable setting min gas price runtime value via extra data field (default: true)                                                                                                                                      | `true`                                                          | BOOLEAN | Advanced   |
| `--plugin-linea-profitability-metrics-buckets`           | List of buckets to use to create the histogram for ratio between the effective priority fee and the calculate profitable priority of the tx (default: [0.1, 0.3, 0.5, 0.7, 0.9, 1.0, 1.1, 1.2, 1.5, 2.0, 5.0, 10.0]) | `[0.1, 0.3, 0.5, 0.7, 0.9, 1.0, 1.1, 1.2, 1.5, 2.0, 5.0, 10.0]` | FLOAT[] | Advanced   |
| `--plugin-linea-compressed-tx-cache-size`                | Variable gas cost in Wei (default: 10000)                                                                                                                                                                            | `10000`                                                         | INTEGER | Advanced   |
