Lineth (formerly the Linea Stack) is the open-source collection of protocol components, onchain contracts,
and operational capabilities that you can use to deploy your own Layer 2 or Layer 3 network, inheriting a
<GlossaryTerm term="Zero-knowledge proof">ZK proof</GlossaryTerm> system and Ethereum-compatible execution.
[Lineth is distinct from Linea](../protocol/linea-vs-lineth.mdx), the public network built on Lineth.

## Why Lineth?

Operators who need more than a public <GlossaryTerm term="Layer 1 (L1)">L1</GlossaryTerm> or
<GlossaryTerm term="Layer 2 (L2)">L2</GlossaryTerm> usually face a three-way tradeoff known as the
institutional blockchain technology trilemma:

- **Privacy and control:** Permissionless networks lack the access, compliance, and data visibility
  controls many institutions require.
- **Liquidity and interoperability:** Standalone chains without a path to Ethereum or Linea become silos.
- **Performance, security, and cost:** Custom L1s add fragmentation, a separate security model, and higher
  maintenance cost.

Lineth is the open-source stack for running your own Ethereum-equivalent network so you can configure all
three, instead of picking one chain type and accepting its gaps.

## Key features

A custom Lineth network has the same protocol foundations as [Linea Mainnet](../network/index.mdx).
<GlossaryTerm term="Operator">Operators</GlossaryTerm> configure access, data availability, and
finalization to match their requirements.
At a high level, Lineth provides:

- **Ethereum-compatible execution:** Run an Ethereum-equivalent network so existing Solidity contracts
  and Ethereum tooling work.
- **Flexible deployment models:** Deploy a public network with onchain data availability, or a
  <GlossaryTerm term="Validium">private validium</GlossaryTerm> with offchain
  data availability and controlled access.
- **Proven state transitions:** <GlossaryTerm term="zk-SNARK" /> proofs verify that state transitions are valid.
  A valid proof means the operator cannot finalize an invalid state transition through the normal proof path.
- **Configurable data visibility:** Choose onchain data availability, or keep transaction data offchain in
  a private validium and control who can access it.
  This is access and data visibility control, not cryptographic private execution.
- **Ethereum-anchored interoperability:** Bridge to Ethereum or Linea through rollup and bridge components.
  Trust assumptions depend on the deployment model, data availability design, verifier configuration, and
  upgrade authority.

Lineth is for technical operators and infrastructure teams who need to run their own network, including
cases that need privacy, governance, or access controls that public networks do not provide.
