Linea Mainnet is the public, permissionless <GlossaryTerm term="zkEVM" /> <GlossaryTerm term="Layer 2 (L2)">
L2</GlossaryTerm> network built on <GlossaryTerm term="Lineth" />.
It processes Ethereum-compatible transactions, generates <GlossaryTerm term="Zero-knowledge proof">
ZK proofs</GlossaryTerm>, and finalizes state to Ethereum.

For protocol mechanics, see [how the Lineth protocol works](../../protocol/overview.mdx).

Linea is a secure, low-cost, and Ethereum-equivalent L2 blockchain built to bring the world
onchain without compromising on security and decentralization.

Linea has been incubated within Consensys. Our mission is to empower developers to build the next generation of decentralized applications and onboard the next billion users to web3.

## Security for all

Built as a layer above Ethereum, Linea inherits the robust security and decentralization of the
Ethereum network while significantly increasing throughput and reducing transaction fees to
negligible amounts.

→ Learn about [Linea's architecture](../../protocol/architecture/index.mdx)

## Advanced zero-knowledge proof technology

By leveraging ZK proofs, Linea removes the seven-day lockup period associated with
<GlossaryTerm term="Fraud proof">fraud proofs</GlossaryTerm> in other L2 solutions built according to the
optimistic rollup model.
Using ZK proofs ensures user funds are always available and can be withdrawn instantly and at no cost.

→ Learn about how proofs fit within [Linea's transaction lifecycle](../../protocol/architecture/index.mdx#transaction-lifecycle)

## True Ethereum equivalence

Linea supports all the features that Ethereum supports.
It's the only zero-knowledge L2 network fully compatible with the
<GlossaryTerm term="Ethereum Virtual Machine (EVM)">EVM</GlossaryTerm>.
This means that any Ethereum-based projects and assets can be seamlessly deployed on and bridged to Linea
without any code base changes.

→ Learn about the small differences between building on [Ethereum and Linea](./ethereum-differences.mdx)

## Fast finality

<GlossaryTerm term="Soft finality" /> within 1s because Linea has short block times and does not reorg
confirmed L2 transactions.

→ Learn about Linea's [finality lifecycle](./transaction-finality.mdx)

## Predictable pricing

Clarity over Linea prices for transactions, how to estimate fees, and how L1 and L2 costs are accounted for.

→ Learn about Linea's [pricing strategy](./predictable-pricing.mdx)

## Recoverable state

Dedicated plugin to reconstruct Linea's state as it was at the last point in time data was finalized.

→ Learn about [recovering state](./recoverable-state.mdx)
