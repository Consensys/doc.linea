This section documents the Lineth smart contract interfaces and implementations.
These pages are generated from the Lineth contract source.

On Linea Mainnet, the finalization contract is `LineaRollup` on Ethereum.
A custom deployment can deploy these contracts at its own addresses, or deploy an equivalent that
satisfies the interfaces its finalization design requires.
See [Smart contracts](../../protocol/architecture/smart-contracts) for how the contracts fit the
protocol.

The sidebar groups this reference into interfaces, libraries, the rollup, the message service, and
the token bridge.
