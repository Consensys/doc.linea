:::info
A custom Lineth deployment can [expose JSON-RPC](../../protocol/architecture/nodes/rpc-services.mdx) on its own endpoint.
Standard Ethereum methods are available on any execution client.
The `linea_` namespace requires <GlossaryTerm term="Linea Besu" /> with the relevant plugins enabled.
Bundler methods and `eth_sendBundle` are served by Linea's public infrastructure.
:::
